- ¿Qué hace input()?
Muestra un mensaje al usuario, espera a que escriba una respuesta y devuelve ese dato al programa
- Quién escribe el dato?
El dato lo escribe el usuario utilizando el teclado
- ¿Dónde acaba almacenado?
La respuesta del usuario termina almacenada en la variable que esté a la izquierda del =
- ¿Qué tipo devuelve siempre input()?
Siempre devuelve un str (texto), aunque el usuario escriba un número.
