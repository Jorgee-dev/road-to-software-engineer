# ¿Cuándo usarías while?

Cuando no sepa cuando acabará el bucle o cuantas veces se hará

# ¿Cuándo usarías for?

Cuando si sepa las veces que se repetirá

# ¿Qué hace range(5)?

Genera los números del 0 al 4

# ¿Por qué range(5) no llega al 5?

Porque hace 0-1-2-3-4 (5 numeros)

# ¿Qué ventaja tiene for frente a while cuando sabes las repeticiones?

Puedes determinarle exactamente lo que quieres que haga el bucle

## Listas

Una lista permite guardar varios valores en una sola variable.

Ejemplo:

usuarios = ["Jorge", "Carlos"]

## append()

Añade un elemento al final de la lista.
usuarios.append("Pedro")

## Recorrer una lista

for usuario in usuarios:
    print(usuario)
