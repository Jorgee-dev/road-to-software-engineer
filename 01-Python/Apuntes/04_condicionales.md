# Condicionales

## if

Sirve para ejecutar un bloque de código solo si se cumple una condición.

## else

Se ejecuta cuando la condición del if no se cumple.

## elif

Permite comprobar una nueva condición si la anterior era falsa.

## and

Las dos condiciones deben ser verdaderas.

## or

Con que una condición sea verdadera es suficiente.

## not

Niega una condición.
Si True pasa a False.
Si False pasa a True.
