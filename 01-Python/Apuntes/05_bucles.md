# ¿Qué es un bucle?

Es una orden que se repite tantas veces mientras una condición siga siendo verdadera.

# ¿Qué hace while?

Decir al programa que mientras no se de x condición siga con el bucle

# ¿Qué significa que un bucle tenga una condición?

Que esa condición debe de cumplirse para que continue el bucle

# ¿Qué es un contador?

Es una forma de llevar la cuenta del numero de veces que se repite algo tanto + como -

# ¿Qué ocurre si la condición nunca deja de cumplirse?

El bucle sería infinito
