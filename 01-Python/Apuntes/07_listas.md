# ¿Qué hace append()?

Añade un elemento al final de una lista.

# ¿Qué hace remove()?

Elimina un elemento de una lista.

# ¿Qué hace in?

Comprueba si un elemento está dentro de una lista o una cadena. Devuelve True o False.

# ¿Qué devuelve len() en una lista?

Devuelve el número de elementos que contiene una lista.
