# ¿Qué hace def?

Define una función con un nombre para poder utilizarla más tarde

# ¿Qué hace return?

Devuelve un valor desde una función para que el programa pueda utilizarlo

# ¿Qué diferencia hay entre print() y return?

print() muestra información al usuario y return devuelve información al programa

# ¿Cuándo usarías una función?

Cuando quiera agrupar varias instrucciones bajo un mismo nombre para reutilizarlas.
