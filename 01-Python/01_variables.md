- ¿Qué es un programa?
Es una lista de instrucciones/ordenes que le damos a la maquina para que ejecute
- ¿Qué es una instrucción?
Es un paso a seguir guiado para alcanzar el objetivo requerido
- ¿Qué es una variable?
Es un nombre que utilizamos para referirnos a un dato almacenado en memoria
- ¿Qué significa = en programación?
Significa le pongo este valor a esta palabra
