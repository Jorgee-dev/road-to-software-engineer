1. ¿Qué problema resuelve Git?
Git permite guardar el historial de un proyecto para poder volver a versiones anteriores, trabajar de forma segura y colaborar con otras personas. (Como un Ctrl + Z)
2. ¿Qué diferencia hay entre Git y GitHub?
Git es en mi ordenador y no necesito de internet mientra que GitHub es una web para subir, enseñar y colaborar con los proyectos
3. ¿Qué es un repositorio?
Una carpeta cuyo contenido está siendo controlado por Git.(Area principal)
4. ¿Qué hace git add?
Prepara los cambios para el siguiente commit.
5. ¿Qué hace git commit?
Guarda el proyecto (como si hicieras una foto)
6. ¿Qué hace git push?
Sube esa "foto" a GitHub / envía los commits locales al repositorio remoto.
7. ¿Qué es VS Code?
Un editor de código
8. ¿Qué hace el PATH?
Una lista de carpetas donde luego Windows buscará los programas
9. ¿Por qué instalamos Bitwarden?
Para tener una mejor gestion de contraseñas y que estas puedan ser mas seguras sin necesidad de aprendernoslas
10. ¿Qué he aprendido hoy?
Muchos conceptos nuevos y gestión ordenada de archivos
